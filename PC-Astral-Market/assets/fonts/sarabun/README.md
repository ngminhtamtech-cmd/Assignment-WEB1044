# Sarabun

Phông chữ chính của PC Market, kiểm tra bằng computed style ngày 17/10/2026. Tác giả: The Sarabun Project Authors / Cadson Demak. Giấy phép SIL Open Font License 1.1 kèm trong OFL.txt.

Font lấy từ Google Fonts và lưu nguyên bản WOFF2; gồm các độ đậm 400, 500, 600, 700, 800, bộ ký tự Latin, Latin mở rộng và tiếng Việt. Website không cần gọi CDN.
